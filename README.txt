Japan Mythic Flow — separate website

This site embeds the original Figma prototype at its final interactive screen. The prototype's own hover, click, overlay and transition behaviors run inside Figma's player. The embedded frame links to the FINAL screen in page 1:3.

To change the prototype, edit the original Figma file. To change the frame used on this site, edit the node-id and starting-point-node-id values in index.html.

If the embedded view is unavailable, select “Open prototype directly” at the bottom-right. Figma's sharing settings control who can view the prototype.
